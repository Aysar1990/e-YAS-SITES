## 🎯 **كيف تعرف التطبيق يستخدم أي مصدر؟**

### **الطريقة 1: افتح Developer Tools**
```
1. اضغط F12 في التطبيق
2. اذهب لـ Console
3. ابحث عن رسائل:

   ✅ "[DB] Using SQLite adapter"
      👉 يستخدم قاعدة بيانات SQLite المحلية

   ☁️ "[DB] Using Supabase adapter"
      👉 يستخدم Supabase السحابية

   🌐 "[API Manager] Using API Client mode: 192.168.x.x"
      👉 متصل بسيرفر عبر الشبكة
```

### **الطريقة 2: تحقق من ملف .env**
```bash
# افتح الملف
notepad .env

# ابحث عن:
DATABASE_TYPE=sqlite    # محلي
DATABASE_TYPE=supabase  # سحابي
```

### **الطريقة 3: من واجهة التطبيق**
```
Settings → Database → Current Mode
- SQLite: أيقونة قاعدة بيانات
- Supabase: أيقونة سحابة
```

## 📂 **الملفات الأساسية لفهم تدفق البيانات**

### **1. Database Adapter Pattern**
```javascript
📁 electron/database/db.js

// يحدد نوع قاعدة البيانات من .env
const dbType = process.env.DATABASE_TYPE || 'sqlite'

if (dbType === 'supabase') {
  adapter = new SupabaseAdapter()  // ☁️ سحابي
} else {
  adapter = new SQLiteAdapter()    // 💾 محلي
}
```

### **2. SQLite Adapter**
```javascript
📁 electron/database/adapters/sqliteAdapter.js

// يتعامل مع ملف tssr.db
prepare(sql) { ... }
exec(sql) { ... }
```

### **3. Supabase Adapter**
```javascript
📁 electron/database/adapters/supabaseAdapter.js

// يتصل بـ Supabase PostgreSQL
initialize() {
  this.supabase = createClient(url, key)
}
```

### **4. Real-time Sync**
```javascript
📁 electron/services/realtimeSync.js

// مزامنة فورية عبر WebSocket
subscribeToChanges(table, callback)
```

## 🔄 **كيفية التبديل بين قواعد البيانات**

### **من SQLite إلى Supabase:**
```bash
# 1. حدّث .env
DATABASE_TYPE=supabase
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_ANON_KEY=xxxx

# 2. أعد تشغيل التطبيق
npm run server
```

### **من Supabase إلى SQLite:**
```bash
# 1. حدّث .env
DATABASE_TYPE=sqlite

# 2. أعد تشغيل التطبيق
npm run server
```

// في Console:
fetch('https://xxxx.supabase.co/rest/v1/sites?limit=1', {
