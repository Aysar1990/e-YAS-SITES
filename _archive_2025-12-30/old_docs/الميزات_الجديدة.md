## 🗄️ Supabase Integration

### قاعدة بيانات سحابية جديدة:
- ✅ **PostgreSQL** كقاعدة بيانات رئيسية
- ✅ **Row Level Security** للأمان
- ✅ **Real-time Subscriptions** للتحديثات الفورية
- ✅ **Cloud Backups** نسخ احتياطي تلقائي

### التبديل بين SQLite و Supabase:
```bash
# في ملف .env
DATABASE_TYPE=sqlite    # للعمل المحلي
DATABASE_TYPE=supabase  # للعمل السحابي
```

## 🔄 Real-time Features

### مزامنة فورية:
- ✅ **WebSocket Server** على Port 3002
- ✅ تحديثات فورية لجميع المستخدمين
- ✅ مؤشر حالة الاتصال
- ✅ إعادة اتصال تلقائي

### الأحداث المدعومة:
| الحدث | الاتجاه | الوصف |
|-------|---------|-------|
| `site:updated` | Server→Client | تحديث بيانات موقع |
| `site:created` | Server→Client | إضافة موقع جديد |
| `site:deleted` | Server→Client | حذف موقع |
| `sync:status` | Server→Client | حالة المزامنة |

## 📋 SpreadsheetView - ميزات الجدول

### 1. **Fullscreen Mode** ⛶
- فتح الجدول في نافذة كاملة
- الخروج بـ **ESC**
- يغطي كامل الشاشة

### 2. **Grid Density** 🎚️
- **⊞ Comfortable** - صفوف كبيرة (40px) - 100 صف
- **⊟ Compact** - متوسط (32px) - 150 صف
- **≡ Dense** - مضغوط (26px) - 200 صف ✨

### 3. **Column Manager** ☰
- إخفاء/إظهار أي عمود
- **Show All** - كل الـ68
- **Essential Only** - 8 أعمدة أساسية فقط

### 4. **Font Size** 🔤
- **A-** تصغير (11px)
- **A+** تكبير (16px)

### 5. **Auto Controls** 📏
- **Auto-fit** - ضبط حسب المحتوى
- **Fit Screen** - ملء الشاشة

## 🔐 Error Boundaries

### معالجة أخطاء شاملة:
- ✅ **GlobalErrorBoundary** - التقاط جميع أخطاء React
- ✅ **AsyncErrorBoundary** - معالجة أخطاء async
- ✅ **RouteErrorBoundary** - أخطاء التنقل و 404

### ميزات المعالجة:
- واجهة مستخدم ودية عند حدوث خطأ
- حفظ الأخطاء في localStorage للتحليل
- زر إعادة المحاولة
- نسخ تفاصيل الخطأ للدعم

## 📊 Excel Reading المحسّن

### تحسينات الاستيراد:
- ✅ **Auto Filter Fix** - قراءة جميع الصفوف
- ✅ **Caching** - تسريع القراءات المتكررة
- ✅ **Progress Reporting** - شريط تقدم
- ✅ **Validation** - التحقق من 68 عمود

### التحقق من البيانات:
- عدد الأعمدة (68 عمود متوقع)
- وجود Site ID
- أنواع البيانات (إحداثيات، أرقام)

## 🔄 Conflict Resolution

### استراتيجيات حل التعارضات:
| الاستراتيجية | الوصف |
|--------------|-------|
| **LAST_WRITE_WINS** | الأحدث يفوز (افتراضي) |
| **MANUAL_REVIEW** | مراجعة يدوية |
| **FIELD_LEVEL_MERGE** | دمج على مستوى الحقول |
| **USER_CHOICE** | اختيار المستخدم |

### مكون ConflictDialog:
- عرض الفروقات بين النسختين
- اختيار حقول محددة من كل نسخة
- تسجيل القرارات للتتبع

## 🚀 كيف تستخدم:

### **الإعداد:**
```bash
# 1. انسخ ملف البيئة
copy .env.example .env

# 2. اختر نوع قاعدة البيانات
# DATABASE_TYPE=sqlite أو supabase

# 3. شغل التطبيق
START_SIMPLE.bat
```

- `/admin/spreadsheet` - عرض الجدول
- `/admin/transform-import` - استيراد Excel
