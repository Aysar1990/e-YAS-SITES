```
START_SIMPLE.bat
```

هذا سيفتح نافذتين:
- 🟦 Vite Dev Server (أزرق)
- 🟥 Electron App (أحمر)

**انتظر 10 ثواني وسيفتح التطبيق تلقائياً!**

## 🔧 إعداد البيئة (مرة واحدة فقط)

### 1. إنشاء ملف .env
```bash
# انسخ الملف النموذجي
copy .env.example .env
```

### 2. إعداد قاعدة البيانات
اختر نوع قاعدة البيانات في ملف `.env`:

```bash
# للعمل المحلي بدون إنترنت
DATABASE_TYPE=sqlite

# للعمل الجماعي عبر السحابة
DATABASE_TYPE=supabase
```

### 3. إعداد Supabase (إذا اخترت supabase)
```bash
# في ملف .env
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_ANON_KEY=your_anon_key_here

# في ملف electron/.env.server (للسيرفر فقط)
SUPABASE_SERVICE_KEY=your_service_key_here
```


### مشكلة: Electron لا يفتح
انتظر 10 ثواني إضافية - Vite يحتاج وقت للتحميل

اضغط Ctrl+R لإعادة تحميل الصفحة

### مشكلة: لا يتصل بـ Supabase
- تأكد من صحة SUPABASE_URL و SUPABASE_ANON_KEY
- تأكد من وجود اتصال بالإنترنت
- تأكد من إنشاء الجداول في Supabase Dashboard
